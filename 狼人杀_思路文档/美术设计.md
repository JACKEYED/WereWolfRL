## 🎯 风格一致性小贴士

为了 12 张看起来像"一套"而不是七拼八凑：

1. **强烈推荐在同一个 ChatGPT 对话里连续生成**——一次发完 12 段，或者一段一段发但都在同一个会话窗口里。DALL-E 会自动记住前面的风格。

2. **第一张满意之后，可以在后续 prompt 里加一句**：
   > 风格请与前一张保持完全一致（线条粗细、配色饱和度、笔触都对齐）。

3. **如果某一张人物长得不对**（比如你想要年轻但出来太老），直接回复 ChatGPT：
   > 让人物看起来更年轻一些 / 表情再温和一点 / 帽子改成XX样式，其他不变。

4. **缩到 32×32 之后细节会丢失很多**——所以人物的"识别特征"要靠**颜色**和**轮廓**而不是细节（眼镜的圆框、辫子的甩向、灯笼的形状这些会保留；眼神细节会糊掉）。我写 prompt 时已经按这个原则突出了配饰。

## B. 角色精灵 texture.png × 12

**关键约束**：96×128 像素 = 3 列 × 4 行 grid，每帧 32×32：
- 第 1 行（下排 y=0~32）：朝下 walk cycle 3 帧
- 第 2 行（y=32~64）：朝左 walk cycle 3 帧
- 第 3 行（y=64~96）：朝右 walk cycle 3 帧
- 第 4 行（y=96~128）：朝上 walk cycle 3 帧

**推荐工具**：**PixelLab.ai**（自带 4-direction sprite generator）或 **Scenario.com**

**通用 prompt（PixelLab 风格）**：
```
4-direction walking sprite sheet, 32x32 per frame, 3 frames per direction
(left foot forward / idle / right foot forward), pixel art style,
Republic-of-China-era Jiangnan villager, transparent background, no shadow baked in,
character full body, head-to-toe visible within 32x32, clean 1-pixel outline.
Style reference: Stardew Valley NPC sprites.

Character: [复制上面 portrait 的角色描述]
```

**注意**：96×128 内塞下全身行走动画极其紧凑，建议先生成 144×192（3×放大）方便编辑，最后再 downsample 到 96×128。

**如果手头没 PixelLab**：退路方案——直接复用现有 12 个旧 texture.png（沿用斯坦福小镇美式角色精灵），在地图上虽然违和，但游戏逻辑不受影响。先把 portrait 换掉，sprite 留到二期。

## D. maze.json 重画

**不是生图任务**，是用 [Tiled Map Editor](https://www.mapeditor.org/) 重新编排 100×140 的地图：
- 用新瓦片图作 tileset
- 在地图上摆出 8 个地点的具体位置
- 标记每个 tile 的 4 层 address（world / sector / arena / game_object）
- 标记 collision

完成后导出 JSON，会生成跟现有 `maze.json` 同结构的文件。地点 address 要跟我之前在 `werewolf.py` 的 `LOCATIONS` 字典里定的 key 对齐，比如：
- `["江南古镇", "听雨茶馆", "雅间", "雅间茶桌"]` ← 对应 `LOCATIONS["teahouse"]`

## GPT 到底能不能直接生成？分三种情况

### ✅ 立绘（12 张头像）—— 能！GPT 直出 + 一步缩放就行

GPT 生成的 1024×1024 像素画，缩到 32×32 完全够用。最适合零基础。

**完整流程**（5 分钟一张）：
1. 在 ChatGPT 里发下面的 prompt，让它出图
2. 把图保存到电脑
3. 用 Windows 自带的"画图"（Paint）打开 → 重新调整大小 → 改成 32×32 像素 → 保存 PNG
4. 替换 `frontend/static/assets/village/agents/陈砚秋/portrait.png`

**直接复制给 GPT 的 prompt（以陈砚秋为例）**：

```
请生成一张像素画风格的角色头像，要求：
- 风格：参考《星露谷物语》(Stardew Valley) 的像素头像
- 构图：只画头部和肩膀，正面或四分之三侧面，居中
- 时代背景：1930 年代民国江南水乡
- 人物：38 岁男性私塾先生，灰色长衫，圆框眼镜，
  细眉小胡子，神情沉静博学，手里若隐若现握着一柄折扇
- 配色：温暖柔和，水墨蓝灰、米白、深木褐为主
- 背景：纯白或浅米色，方便后期抠图
- 输出比例：1:1 正方形
不要文字、不要水印、不要 logo。
```

把上面的"38 岁男性…手里握着折扇"换成另外 11 个人的描述就行（用我前一轮给的关键词）。

---

### ❌ 角色行走动画（sprite.png）—— GPT 做不了

这个是 96×128 像素的 "雪碧图"——3×4 = 12 个小格子，每个格子是同一个人一帧动作，要让人物面朝下/左/右/上 各走 3 帧。GPT/DALL-E 不能精确控制"同一个人在 12 个格子里动作连贯"。

**三个出路**：

1. **最省事**：不画，沿用旧的美式精灵。地图上角色长得像外国人，但**游戏逻辑完全不受影响**，只是回放看着违和。
2. **花点钱**：开 [PixelLab.ai](https://pixellab.ai) 一个月，它有"sprite sheet 生成"按钮，描述一下角色就能出 4 方向动画。一个月够你做完 12 个，~$15。
3. **找人做**：Fiverr / 闲鱼搜"像素角色 sprite"，单个 ¥30-100，12 个 ~¥1000 内能搞定。

---

### ⚠️ 地图瓦片（tilemap.png）—— GPT 能"画看着像"，但不能"真正拼接"

瓦片图是一张大图（512×512），里面切成 256 个 32×32 小格，每个格子是一种地砖/草地/墙角。**关键要求**：相邻格子能无缝拼接。GPT 不懂这种"边缘对齐"。

**实事求是的建议**：**别自己生成瓦片**，直接买现成的。

去 [itch.io](https://itch.io/game-assets/tag-pixel-art/tag-tileset) 搜：
- "Ancient China tileset"
- "Asian village tileset"
- "Japanese feudal tileset"（日本和中国古镇视觉相近，能凑合）

价格 $5-30，能买到完整的房屋/街道/室内瓦片包。然后用 **Tiled Map Editor**（免费）把这些瓦片拼成 100×140 的地图。
