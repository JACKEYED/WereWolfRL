## 三个有意为之的"信息泄露"设计（用于增加博弈深度）

1. **神职夜晚地点固定** → 狼人推理空间：若某玩家白天总往观星楼方向走，可推测是预言家。强迫神职做"反侦察"决策。
2. **医馆 NPC 流言**：店伙计会在次日清晨随机透露"昨夜有人来取药"（不指名），给狼队提供模糊女巫信号，也可被狼伪装。
3. **茶馆雅间容量硬上限 3 人** → 私聊必须排队/换房，决策成本本身就是策略数据。

## NPC 流言是什么

意思是：**地图上不是玩家的"杂角"**（医馆店伙计、茶馆跑堂、夜市小贩、码头船家），他们会在每天清晨/黄昏向附近玩家"透露"昨天的所见所闻，但**信息是模糊、可能错、可能被狼伪造**的。

### 一个具体例子

夜晚发生了：女巫（林宛娘）去医馆取了解药救人。

次日清晨，医馆店伙计在广场旁碰到几个玩家，会说一句：

> "昨夜三更，有位姑娘来取过药——天黑没瞧清是哪家的。"

这条信息会进入**那几个在场玩家的私有记忆**，但不进入全员公开记忆。

### 为什么有用（对 RL 训练和博弈）

1. **半结构化情报源**：好人神职身份不会被直接点名，但能被推断 → 给狼队提供推理任务，也给神职"反侦察"压力（你既要用药，又要避免规律被发现）。
2. **天然噪声**：流言会带误差（"姑娘"可能错认成"小生"），LLM Agent 必须学会判断流言可信度——这是非常珍贵的训练信号。
3. **狼人伪造空间**：狼人可以反过来引用流言"我也听跑堂说的"，制造假信息。这给狼队语言伪装训练材料。
4. **可量化**：每条流言都是 `(source_npc, content, accuracy, audience)` 结构，能直接进 RL 观测向量。

### 实现成本

新增一个独立的 `gossip.py` 模块（约 200-300 行）：
- 监听夜晚事件 → 按"扭曲规则"生成模糊版本
- 按地点把流言分发给清晨/黄昏经过该 NPC 的玩家
- 写入对应玩家的 `private_log`

不改规则引擎，是纯外挂模块。

### 不做会怎样

也能跑——好人就只能靠"自己亲身经历 + 公开发言"推理。这是标准狼人杀的信息密度。

## 我的建议

**初版先做**。原因：你的项目最终目标是 RL 训练，流言机制提供的"半可信中间情报"几乎是给本地 Qwen-7B 量身做的训练素材。如果初版就有，后续训练数据自带噪声鲁棒性；后补的话，所有早期 checkpoint 都得废弃重跑。
